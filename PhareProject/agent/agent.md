## Permissions

- Rechercher des fichiers dans la base de données
- Envoyer des liens de téléchargement aux étudiants
- Répondre aux questions sur les matières disponibles
- Lister les documents disponibles par catégorie

- Ne jamais supprimer ou modifier des fichiers
- Ne pas répondre à des sujets hors contexte scolaire
- Ne pas partager les clés API ou mots de passe
